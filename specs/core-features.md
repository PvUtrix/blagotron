# Core Features Specification

## 1. Self-Discovery & Awareness Tools

### 1.1 Life Balance Wheel
**Purpose**: Visual representation of life satisfaction across multiple domains

**Features**:
- Customizable life domains (default: Career, Health, Relationships, Personal Growth, Finances, Recreation, Environment, Contribution)
- Numeric rating (0-10) for each domain
- Visual wheel/radar chart display
- Historical tracking to see changes over time
- Ability to set target levels for each domain
- Export/share functionality

**Data Collected**:
- Domain scores (timestamp, domain, score)
- User notes on each domain
- Goals per domain

### 1.2 Energy & Flow Tracking
**Purpose**: Identify activities and contexts that energize vs. drain

**Features**:
- Quick logging of activities with energy level (+3 to -3)
- Flow state indicators (challenge level, skill level, engagement)
- Interest/curiosity ratings
- Context tags (location, time of day, people present)
- Pattern recognition and insights
- Recommendations based on energy patterns

**Data Collected**:
- Activity logs (activity, duration, energy delta, flow indicators)
- Context metadata
- Biometric data (if integrated with wearables)

### 1.3 Personal Rhythms & Biorhythms
**Purpose**: Understand individual patterns for optimal planning

**Features**:
- Sleep quality and duration tracking
- Energy level patterns throughout day/week/month
- Productivity peak times identification
- Integration with smart watches and fitness trackers
- Circadian rhythm insights
- Recommendations for scheduling based on personal patterns

**Data Collected**:
- Sleep data
- Energy measurements
- Activity timing
- Performance metrics

### 1.4 Values & Goals Framework
**Purpose**: Clarify personal values and set aligned goals

**Features**:
- Values identification exercises
- Goal setting across life domains
- SMART goal templates
- Long-term vision (1, 3, 5, 10 year horizons)
- Quarterly and monthly goal breakdown
- Alignment checks between values and goals
- Progress tracking and reflection

**Data Collected**:
- Personal values list
- Goals (short, medium, long-term)
- Progress updates
- Reflection notes

## 2. Planning & Management Tools

### 2.1 Adaptive Life Constructor
**Purpose**: Build days and weeks based on current state and context

**Features**:
- Current state assessment (energy, mood, time available)
- Context-aware suggestions (work day, weekend, vacation, etc.)
- Activity library categorized by:
  - Time required (5, 10, 20, 30, 60+ minutes)
  - Life domain
  - Energy requirement
  - Solo vs. social
- Drag-and-drop scheduling interface
- Template creation for recurring patterns
- Quick adaptation to changes
- Integration with calendar apps

**Data Collected**:
- Scheduled activities
- State assessments
- Template usage
- Actual vs. planned comparisons

### 2.2 Priority & Attention Management
**Purpose**: Help focus on what matters most

**Features**:
- Task capture and organization
- Eisenhower Matrix (urgent/important grid)
- Limited WIP (work in progress) enforcement
- Focus time blocking
- Distraction logging
- Weekly/monthly priority review
- Goal alignment visualization

**Data Collected**:
- Task list
- Priority rankings
- Time allocation
- Distraction events

### 2.3 Coaching Questions & Reflection
**Purpose**: Facilitate self-reflection and insight

**Features**:
- Prompted reflection questions
- Customizable question sets
- Daily/weekly/monthly reflection rhythms
- Free-form journaling
- Question templates based on Stanford Designing Your Life:
  - "What worked well this week?"
  - "What drained my energy?"
  - "What am I learning about myself?"
  - "What would I do differently?"
- Searchable reflection archive

**Data Collected**:
- Reflection entries
- Question responses
- Journal entries

## 3. Learning & Inspiration

### 3.1 Activity Ideas Library
**Purpose**: Inspire with ideas for activities across life domains

**Features**:
- Curated activity database:
  - 5-minute activities (meditation, gratitude practice, quick walk)
  - 10-minute activities (stretching, reading, connecting with friend)
  - 20-minute activities (exercise, learning module, creative project)
  - Longer activities (hobbies, social events, nature outings)
- Filtering by life domain, time, energy level
- User-contributed activities
- "Try this" recommendations
- Progress tracking for new habits

**Data Collected**:
- Activity database
- User tries and ratings
- Success stories

### 3.2 Day-in-the-Life Examples
**Purpose**: Learn from others' routines and approaches

**Features**:
- Anonymous user routine shares
- Public figure routines (curated)
- Profession/role-specific patterns
- Before/after transformation stories
- Commentary on what works and why
- Adaptability notes
- "Inspiration board" for collecting ideas

**Data Collected**:
- Routine templates
- User stories
- Engagement metrics

### 3.5 Impact & Contribution Opportunities

**Features**:
- Charity and volunteer opportunity database

- Local community events

- Opportunity database

## Success Criteria per Feature

Each feature should be evaluated on:
1. **User Value**: Does it clearly serve a user need?
2. **Engagement**: Do users regularly use it?
3. **Outcomes**: Does it contribute to user well-being?
4. **Simplicity**: Is it intuitive and easy to use?
5. **Performance**: Does it work reliably and fast?
6. **Privacy**: Does it respect user data appropriately?

Features that don't meet these criteria should be reconsidered or removed.
